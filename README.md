# Corporate Transport & Fleet Management ERP

## Overview

A custom ERP solution developed using **Odoo 17 Community** for managing corporate transport operations.

### Features

- Driver Management
- Vehicle Management
- Route Management
- Trip Scheduling
- Leave Management
- Fleet Expenses
- Dashboard
- Reports

### Technologies

- Odoo 17 Community
- Python
- PostgreSQL
- XML
- Git & GitHub
