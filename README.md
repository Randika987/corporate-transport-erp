# 🚍 Corporate Transport Management System (Odoo 17)

## 📌 Overview

Corporate Transport Management System is a custom ERP solution developed using **Odoo 17 Community Edition** to streamline corporate fleet operations. The system manages drivers, vehicles, assignments, trips, maintenance, fuel operations, dashboards, analytics, and PDF reports in one integrated platform.

---

## ✨ Features

### Driver Management
- Driver Registration
- License Validation
- License Expiry Alerts
- Driver PDF Reports

### Vehicle Management
- Vehicle Registration
- Service Due Notifications
- Seating Capacity Automation
- Vehicle PDF Reports

### Vehicle Assignment
- Assign Drivers to Vehicles
- Assignment Tracking

### Trip Management
- Start / Complete Trips
- Distance Tracking
- Odometer Tracking
- Trip Reports

### Fleet Operations
- Fuel Management
- Maintenance Management
- Fuel Efficiency Calculation
- Cost per KM Analysis

### Dashboard
- KPI Cards
- Fleet Statistics
- Service Alerts
- License Alerts
- Quick Actions

### Reports
- Driver Report
- Vehicle Report
- Trip Report
- Fleet Operation Report

## ⚙ Installation

```bash
git clone https://github.com/Randika987/corporate-transport-erp.git
```

Copy the module into:

```
custom_addons/
```

Restart Odoo.

Update Apps List.

Install **Corporate Transport Management System**.
